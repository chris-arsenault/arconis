# 0007 — Permissive licensing and original interactions

- Status: Accepted
- Date: 2026-11-06

## Context

The product brief prohibits licensing encumbrances. The owner asked for InfiniPaint-inspired interactions, and InfiniPaint's
source is GPL.

## Decision

Arconis is MIT licensed and uses permissively licensed dependencies. InfiniPaint-inspired interactions are implemented
independently, with none of its source or assets.

## Alternatives considered

- **InfiniPaint's GPL code** — the owner directed original code instead.
- **Commercial editor licenses and restrictive copyleft dependencies** — the brief rejects these.

## Consequences

Every interaction inspired by InfiniPaint must be written here. New dependencies need a license check.
